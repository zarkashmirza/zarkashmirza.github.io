Some Selected Works

Mystic Pages

Overview: Mystic Pages is a high-fidelity mobile application prototype designed as a digital companion for an independent literary bookstore. The core objective of this project was to translate a cozy, tactile bookstore experience into a seamless, modern mobile interface without sacrificing editorial elegance.

Key Engineering & Design Highlights

  • Hardware-Aware Layout Constraints: Engineered with optimized vertical safe-zone margins specifically calculated to accommodate modern mobile hardware, including the iPhone Dynamic Island layout.
  • Editorial Typographic System: Utilizes a deliberate font pairing—Playfair Display for high-end editorial headings and book titles, paired with Plus Jakarta Sans for clean, highly legible UI body text and navigation elements.
  • Atmospheric Design Tokens: Built upon a custom-curated color palette featuring Obsidian Ink, Arcane Gold, Sage, Parchment, White, and Slate Dust to evoke a warm, immersive literary aesthetic.
  • Mobile Ergonomics & Navigation: Features thumb-friendly touch targets, a streamlined catalog search flow, and fluid bottom-sheet interactions designed for effortless one-handed browsing.

Finley Books

Overview: Finley Books is a responsive single-page application bookstore layout designed to explore modern layout engines and structured component design. The project centers around showcasing a curated series of fictitious satirical programming books within a clean, high-performance web interface.

Key Engineering & Design Highlights

  • Advanced CSS Grid Architecture: Utilizes robust CSS Grid placement mechanics to organize and align product inventory cards dynamically across varying viewport widths.
  • Component-Driven Card Layouts: Implements modular, reusable card patterns that maintain structural integrity and visual rhythm without relying on rigid, hardcoded dimensions.
  • Thematic Content Design: Blends minimalist modern web standards with a playful, satirical catalog focus, demonstrating an ability to translate functional data structures into engaging user-facing storefronts.
  • Responsive Single-Page Flow: Built with a lightweight, optimized single-page architecture ensuring fast initial load times and seamless navigation.
